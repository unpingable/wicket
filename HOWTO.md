# Wicket: bounded local lane

Wicket classifies a supplied intent; it does not perform the described action
and it is not a source of authority.

```sh
cargo test
cargo run -- edit README.md \
  --because 'inspect the public tutorial boundary' \
  --standing recommend --brief
```

To exercise the maintained Wicket Guard lineage, create a local unified diff
fixture and run:

```sh
cargo run --example cook_from_diff -- /absolute/path/to/change.diff
cargo test --test cook_from_diff_regression
```

The output is an admissibility classification and receipt, not proof that the
change was applied or externally authorized.

Current public source: <https://github.com/unpingable/wicket>
