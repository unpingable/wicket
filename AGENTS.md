# Agent guide

Run `cargo test`, `cargo fmt --check`, and
`cargo clippy --all-targets -- -D warnings` before claiming a change is ready.
Preserve unrelated fixtures and local changes.

For public documentation, call the repository **Constellation Wicket**, but
keep links at `https://github.com/unpingable/wicket` until migration is
actually complete. Keep crate, command, schema, and protocol names unchanged.
Describe Wicket Guard as an absorbed
historical lane implemented by `examples/cook_from_diff/` and its regression;
do not imply that the husk repository remains a separate runtime component.

Wicket classifies one caller-cooked intent. It does not execute the operation,
resolve standing, or mint authority.
